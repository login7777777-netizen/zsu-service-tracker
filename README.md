# ZSU Service Tracker 🇺🇦

## 🇺🇦 Опис українською

Сайт для обрахунку терміну служби військовослужбовців Збройних Сил України.

### Призначення

Цей інструмент створено для підтримки українських захисників — він дозволяє швидко та зручно визначити залишок служби, мотивує та підкреслює важливість кожного дня на фронті.

### Особливості

- 🇺🇦 Українська та 🇬🇧 англійська версії
- 📱 Адаптивний дизайн
- 🔐 Без трекерів, без збору даних
- 🛡️ Код відкритий, але захищений

### Авторство

Цифрова ініціатива на підтримку ЗСУ.  
Без персональних даних. Без компромісів.  
Слава Україні 💙💛

---

## 🇬🇧 English Description

A website for calculating the service duration of military personnel in the Armed Forces of Ukraine.

### Purpose

This tool was created to support Ukrainian defenders — it helps quickly and clearly determine the remaining service time, motivates, and highlights the importance of every day on the front line.

### Features

- 🇺🇦 Ukrainian and 🇬🇧 English versions
- 📱 Responsive design
- 🔐 No trackers, no data collection
- 🛡️ Open-source code with strict protection

### Authorship

A digital initiative in support of the Armed Forces of Ukraine.  
No personal data. No compromises.  
Glory to Ukraine 💙💛
